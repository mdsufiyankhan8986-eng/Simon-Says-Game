# Simon Says Game

Simon Says Game is an interactive browser-based memory game built using HTML, CSS, and JavaScript.
The game generates a sequence of colors that the player needs to remember and reproduce in the correct order. With each successful level, a new color is added to the sequence, making the game progressively more challenging.

## How It Works

1. Press any key to start the game.
2. The game displays a random color.
3. Remember the color shown by the game.
4. Click the buttons in the same sequence.
5. If the sequence is correct, the game moves to the next level.
6. A new color is added to the sequence at each level.
7. If the player selects the wrong color, the game ends.
8. The current score is displayed after the game ends.
9. Press any key to start a new game.
